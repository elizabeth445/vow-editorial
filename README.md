# Vow Editorial

Персональное свадебное приглашение на украинском языке: интерактивный бумажный конверт, история пары, календарь, программа, дресс-код, локация, RSVP и пожелания.

## Запуск и проверка

Нужны Node.js и pnpm. Проект использует менеджер пакетов, указанный в package.json; версии зависимостей закреплены в pnpm-lock.yaml.

```sh
pnpm install --frozen-lockfile
pnpm run dev
```

Адрес сайта появится в терминале. Полная проверка:

```sh
pnpm run verify
```

Команда выполняет ESLint, TypeScript, Playwright и production-сборку. Для тестов на машине без Chrome установите браузер:

```sh
pnpm exec playwright install chromium
```

## Настройка

Данные свадьбы и гостевые профили находятся в src/data/weddingConfig.ts. Персонализация определяется параметром guest. Активные фотографии и бумажная текстура находятся в public/images; шрифты поставляются локально через Fontsource.

RSVP и пожелания сохраняются в localStorage этого браузера и не отправляются организаторам. Backend и секретные переменные окружения не используются. Приглашение поддерживает пропуск и повтор конверта, мобильное меню, скачивание календаря и prefers-reduced-motion.

## Production

```sh
pnpm run build
pnpm run preview
```

Для Vercel: preset Vite, команда сборки pnpm run build, выходной каталог dist. Публикация хостинга — отдельное действие. Самодостаточный HTML-файл можно создать командой pnpm run export:html; полученный HTML не хранится в Git.

## Проверки интерфейса

Playwright проверяет ширины 320, 390, 768, 1024 и 1440 px, стадии конверта, клавиатуру, мобильное меню, RSVP, персонализацию, календарь, сохранение пожеланий и reduced motion. Генерируемые скриншоты и отчёты исключены из Git. Agentation доступен только в режиме разработки.
