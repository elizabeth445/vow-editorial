Откройте wedding-invitation.html двойным кликом в браузере.
Сервер и установка npm не нужны: фотографии, шрифты, стили и анимации встроены.

Ответы RSVP и пожелания сохраняются только в этом браузере на этом устройстве.
Чтобы увидеть конверт повторно, используйте кнопку в конце страницы.
Для персонального приглашения добавьте к адресу файла ?guest=olena
Другие варианты: default, couple, family-kovalenko, andrii
Ссылкам на Google Maps и ресторан нужен интернет.

Повторно создать HTML после изменения исходного сайта:
npm run export:html
Проверить HTML в Chrome:
node tests/standalone-smoke.mjs
